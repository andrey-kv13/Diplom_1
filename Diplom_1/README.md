# QA Python Diplom - Burger Management System

## Описание проекта

Проект представляет собой систему управления бургерами, включающую в себя классы для работы с булочками, ингредиентами, бургерами и базой данных. Система позволяет создавать бургеры, добавлять ингредиенты, рассчитывать стоимость и генерировать чеки.

## Структура проекта


## Основные классы

### Burger
Основной класс для работы с бургерами:
- `add_ingredient(ingredient)` - добавление ингредиента
- `remove_ingredient(index)` - удаление ингредиента по индексу
- `move_ingredient(index, new_index)` - перемещение ингредиента
- `set_buns(bun)` - установка булочки
- `get_price()` - получение общей стоимости
- `get_receipt()` - генерация чека

### Bun
Класс для работы с булочками:
- `get_name()` - получение названия
- `get_price()` - получение цены

### Ingredient
Класс для работы с ингредиентами:
- `get_name()` - получение названия
- `get_price()` - получение цены
- `get_type()` - получение типа (соус/начинка)

### Database
Класс для работы с данными:
- `available_buns()` - получение списка доступных булочек
- `available_ingredients()` - получение списка доступных ингредиентов

### Использование моков
Моки применяются для:
- Тестирования ошибок при расчете цены булочки (`test_get_price_bun_error`)
- Тестирования ошибок при расчете цены ингредиента (`test_get_price_ingredient_error`)
- Тестирования ошибок при генерации чека ингредиента (`test_get_burger_receipt_ingredient_error`)
- Симуляции сбоев внешних систем и некорректных данных

### Фикстуры
Проект использует pytest-фикстуры для подготовки тестовых данных:
- **`burger`** - пустой бургер для тестирования
- **`bun`** - тестовая булочка
- **`ingredient`** - тестовый ингредиент
- **`burger_with_ingredients`** - бургер с ингредиентами (без булочки)
- **`burger_with_bun_and_ingredients`** - бургер с булочкой и ингредиентами
- **`mock_ingredient_with_error`** - мок ингредиента с ошибкой цены
- **`mock_ingredient_name_error`** - мок ингредиента с ошибкой имени
- **`mock_bun_with_error`** - мок булочки с ошибкой цены

### Параметризованные тесты
Проект использует `@pytest.mark.parametrize` для эффективного тестирования:
- **`test_remove_burger_ingredient`** - тестирует удаление ингредиентов по 6 различным индексам
- **`test_move_burger_ingredient`** - тестирует перемещение ингредиентов в 6 различных позиций
- **`test_get_bun_with_name_and_price`** - тестирует создание булочек с 4 различными параметрами

## Примеры использования

### Создание бургера
```python
from burger import Burger
from database import Database

# Создание бургера
burger = Burger()

# Получение данных из базы
db = Database()
buns = db.available_buns()
ingredients = db.available_ingredients()

# Настройка бургера
burger.set_buns(buns[0])  # Установка булочки
burger.add_ingredient(ingredients[0])  # Добавление ингредиента

# Получение информации
price = burger.get_price()
receipt = burger.get_receipt()
print(f"Цена: {price}")
print(f"Чек:\n{receipt}")
```

### Работа с ингредиентами
```python
# Добавление нескольких ингредиентов
for ingredient in ingredients[:3]:
    burger.add_ingredient(ingredient)

# Удаление ингредиента
burger.remove_ingredient(0)

# Перемещение ингредиента
burger.move_ingredient(0, 2)
```
